# AbiturientApp1

Приложение **Windows Forms (C#)** для ведения базы данных абитуриентов в рамках курсовой работы по теме:
**«Разработка прикладной программы на языке программирования C#»**.

## 1. Назначение проекта

Программа предназначена для:
- хранения записей об абитуриентах;
- добавления, редактирования и удаления записей;
- поиска записей по выбранному полю;
- анализа школ по количеству абитуриентов со средним баллом выше 4;
- сохранения данных в текстовый файл.

## 2. Технологии

- Язык: **C#**
- UI: **Windows Forms**
- Платформа: **.NET Framework 4.7.2**
- IDE: **Visual Studio 2022 (рекомендуется Community)**

## 4. Архитектура и классы

### 4.1 `Abiturient` (`AbiturientApp/AbiturientApp.cs`)
Модель записи абитуриента:
- `FullName` — ФИО;
- `BirthYear` — год рождения;
- `SchoolNumber` — номер школы;
- `AverageScore` — средний балл.

Основные методы:
- `ParseFromString(string line)` — создание объекта из строки формата `ФИО;Год;Школа;Балл`;
- `ToString()` — сериализация записи в строку для сохранения.

### 4.2 `DatabaseManager` (`AbiturientApp/DatabaseManager.cs`)
Класс управления файловой базой данных.

Методы:
- `LoadData()` — загрузка списка из файла;
- `SaveData(List<Abiturient>)` — сохранение списка в файл;
- `AddRecord(...)` — добавление записи;
- `UpdateRecord(...)` — обновление записи по индексу;
- `DeleteRecord(...)` — удаление записи по индексу;
- `Search(...)` — поиск по полям: `ФИО`, `Год рождения`, `Школа`, `Средний балл`;
- `FindBestSchool(...)` — поиск школы/школ с максимальным количеством абитуриентов, у которых `AverageScore > 4`.

### 4.3 `Form1` (`AbiturientApp/Form1.cs`)
Главная форма приложения:
- хранит текущий список `abiturientsList`;
- загружает данные из `abiturients.txt` при запуске;
- обновляет `DataGridView`;
- обрабатывает действия кнопок:
  - `Добавить`
  - `Редактировать`
  - `Удалить`
  - `Найти`
  - `Анализ школ`

### 4.4 `InputForm` (`AbiturientApp/InputForm.cs`)
Форма ввода/редактирования одной записи.

Валидация:
- ФИО не пустое;
- год рождения — целое число;
- школа — целое число;
- средний балл — число в диапазоне `0..5`;
- поддерживается ввод среднего балла через `,` и `.`.

## 5. Интерфейс

Главная форма содержит:
- `DataGridView` для отображения списка абитуриентов;
- кнопки `Добавить`, `Редактировать`, `Удалить`, `Анализ школ`;
- блок `Поиск`:
  - `cbSearchField` (поле поиска),
  - `tbSearchValue` (значение),
  - `btnSearch` (`Найти`).

## 6. Формат хранения данных

Данные сохраняются в файл `abiturients.txt` (в рабочей директории запуска приложения).

Формат строки:
```text
ФИО;Год рождения;Школа;Средний балл
```

Пример:
```text
Иванов Иван Иванович;2005;15;4.7
```

## 7. Функциональные сценарии

### 7.1 Добавление
1. Нажать `Добавить`.
2. Заполнить форму.
3. Нажать `ОК`.
4. Запись появится в таблице и сохранится в файл.

### 7.2 Редактирование
1. Выбрать запись в таблице.
2. Нажать `Редактировать`.
3. Изменить данные и нажать `ОК`.

### 7.3 Удаление
1. Выбрать запись.
2. Нажать `Удалить`.
3. Подтвердить удаление.

### 7.4 Поиск
1. Выбрать поле в `cbSearchField`.
2. Ввести значение.
3. Нажать `Найти`.

Поведение:
- пустое значение — сообщение: «Введите значение для поиска!»;
- нет совпадений — сообщение о том, что записи не найдены;
- при совпадениях показывается выборка результатов.

### 7.5 Анализ школ
1. Нажать `Анализ школ`.
2. Показать номер(а) школы с максимальным числом абитуриентов, у которых балл > 4.

## 8. Сборка и запуск

## 8.1 Требования
- Windows;
- Visual Studio 2022;
- установлен workload **«Разработка классических приложений .NET»**;
- установлен targeting pack **.NET Framework 4.7.2**.

> В средах без reference assemblies для .NET Framework 4.7.2 сборка завершится ошибкой `MSB3644`.

### 8.2 Запуск в Visual Studio
1. Открыть `AbiturientApp.slnx`.
2. Выбрать конфигурацию `Debug` и платформу `Any CPU`.
3. Выполнить `Сборка` → `Собрать решение` (`Ctrl+Shift+B`).
4. Запустить `F5`.

## 9. Частые ошибки

- `CS0246` — отсутствует класс/неверный namespace.
- `CS0103` — несоответствие имени контрола в Designer и коде.
- Ошибка чтения файла — неверная рабочая директория или повреждённый формат строки.
- Неверный ввод балла/чисел — исправить формат ввода в форме.
